# Yojana Saathi (योजना साथी)

Find the government schemes you're eligible for, in plain English and Hindi, and see your **Sarkari Kundli**: a chart of every benefit you can access across your life.

> Yojana Saathi is an independent project, not affiliated with the Government of India. Verify details on official portals.

**Stack:** Next.js 16 (App Router, TypeScript strict), Tailwind CSS 4 + customised shadcn/ui, next-intl (en/hi), next-themes, Framer Motion.

## Run locally
```bash
cd apps/yojana-saathi
npm install
npm run dev        # http://localhost:3000 (English) and /hi (Hindi)
```

_Full docs (adding schemes, Supabase, deploying) land with the later build phases._
