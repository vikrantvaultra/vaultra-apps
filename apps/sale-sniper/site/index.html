Step 1

Install karo

  1. Zip download karo

    Upar wala Download button dabao. File: {{FILENAME}}

  2. Unzip karo

    Windows: zip pe right-click → Extract All. Mac: zip pe double-click.

    Andar sale-sniper naam ka folder milega. Isse kisi pakki jagah rakho (jaise Documents) — delete mat karna, Chrome isi folder se chalata hai.

  3. Extensions page kholo

    Ye address copy karo aur Chrome ke address bar me paste karke Enter dabao:

    chrome://extensions

    Edge me edge://extensions, Brave me brave://extensions.

  4. Developer mode ON karo

    Page ke top-right me Developer mode ka toggle on karo.

  5. Load unpacked → sale-sniper folder

    Load unpacked dabao aur wahi sale-sniper folder chuno jiske andar manifest.json hai. Zip file nahi, folder.

  6. ⚡ pin kar lo

    Toolbar me 🧩 puzzle icon → Sale Sniper ke aage 📌. Ab ⚡ hamesha dikhega.

Step 2

Sale se pehle setup

  1. Usi Chrome me login karo

    Amazon.in aur Flipkart pe isi Chrome profile me login karo. Default delivery address aur payment method pehle se save rakho.

  2. Product link + max price

    Product page kholo → ⚡ → max price daalo → Add to sale list.

    Ya dashboard (⚡ → 🎙) me bolo/likho: “iPhone 15 128GB under 65k on Flipkart”.

  3. Sale ka time set karo

    Har item pe Sale starts me sale ka time daalo (jaise 8 Oct, 12:00 AM). Sale Sniper thoda pehle tab khol ke ready rahega.

  4. Aaj hi dry run karo

    Kisi sasti cheez pe Start now dabao. Sale Sniper Buy Now se checkout tak jayega aur final button / payment page pe ruk jayega. Is public version me auto order hamesha OFF hai, isliye dry run me kuch order nahi hoga — bas wahan se tab band kar do.

  5. Sale ke time windows khuli rakho

    Har item ki chhoti Chrome window khulegi. Unhe minimize ya cover mat karna — Chrome chhupe pages ko slow kar deta hai. Payment page aaye toh OTP/UPI tum approve karo.

Seedhi baat 🤝

  • 💳Payment hamesha tum karte ho. Sale Sniper payment page pe ruk jaata hai. OTP, UPI PIN, CVV ya card number kabhi type nahi karta.
  • 🎯Stock ki guarantee nahi. Lakhs log same deal pe hote hain. Ye bas tumhare shuru ke kuch seconds bachata hai.
  • 🔒Tumhara data tumhare browser me. List aur settings Chrome storage me rehti hain. Koi server, koi account, koi tracking nahi — extension sirf Amazon.in aur Flipkart pages pe chalta hai.
  • 🧪Chrome Web Store pe nahi hai (abhi). Isliye Developer mode chahiye, aur update apne aap nahi hota — naya version isi page se lena.
  • ⚖️Store rules. Amazon/Flipkart ki terms automated shopping allow na karein, aisa ho sakta hai. Sirf apni shopping ke liye use karo; refresh speed jaan-boojh ke limited hai.
  • 🛠️Store pages badalte rehte hain. Kabhi koi button nahi mila toh Sale Sniper “Needs you” dikha ke tumhe bula lega.
Help

Kuch atka?

“Manifest file is missing or unreadable”

Galat folder chuna hai. Zip ya bahar wala folder nahi — wo sale-sniper folder chuno jiske andar seedha manifest.json dikhe. Pehle unzip karna zaroori hai.

“Load unpacked” button dikh hi nahi raha

chrome://extensions pe top-right ka Developer mode on karo. Office/college laptop pe admin ne ye band kiya ho sakta hai — tab personal laptop use karo.

Chrome bolta hai “Disable developer mode extensions”

Unpacked extensions pe ye warning normal hai. Disable mat dabao — popup band (✕) kar do.

Product page pe kuch nahi ho raha

Install ke baad pehle se khule Amazon/Flipkart tabs reload karo. Check karo ki usi Chrome profile me login ho.

Dashboard me item ka status dekho — “Needs you” ho toh wahi likha hoga kya karna hai (login, captcha, quantity…).

Sale me slow lag raha / Buy Now nahi dabaya

Sale Sniper wali windows visible rakho, minimize mat karo. Store captcha maange toh tum solve karo — Sale Sniper wahin se aage badhega.

Naya version kaise update karein?

Naya zip yahan se download karo, unzip karke purane sale-sniper folder ki files replace karo (same jagah). Phir chrome://extensions me Sale Sniper card pe ↻ dabao. Same folder rakhoge toh tumhari list bachi rahegi.

Download sahi hai, kaise verify karun?

File ka SHA-256 upar wale checksum se match karo:

Mac: shasum -a 256 {{FILENAME}}
Windows: certutil -hashfile {{FILENAME}} SHA256

Phone pe chalega?

Nahi. Chrome extensions Android/iPhone pe install nahi hote. Laptop ya desktop pe Chrome, Edge ya Brave chahiye.
